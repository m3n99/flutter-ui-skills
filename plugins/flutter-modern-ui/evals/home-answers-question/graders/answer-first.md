PASS if ALL of these hold: (1) within the first two content blocks of the proposed home screen (not counting a plain title or search bar) the owner sees what needs attention today: today's bookings (who, where, when) or which clients haven't paid; (2) the reply names one primary action for the screen (for example add a booking, mark done, send a reminder).

FAIL if the screen leads with a greeting ("Good morning, …"), or its main content is a grid of statistic tiles with no list of today's bookings or unpaid clients, or it is a menu of features.
