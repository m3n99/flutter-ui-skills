PASS if the empty state's text says what will appear here or what the user can do first, and the button label names its action with a verb and an object (for example "New order", "Add order", "Create your first order").

FAIL if the text is a placeholder such as "No data" or "Nothing found" with no next step, or the button says only "Add", "OK" or "Submit".
